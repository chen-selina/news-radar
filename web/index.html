      版本紀錄

        判斷規則

        1. 標題中的詞權重 ×1.5。
        2. 同一句中詞前 5 字內出現「未、不、無、沒有、並非」會把分數反轉，例如「未見砍單」算利多。
        3. 前方有「大幅、強勁、明顯」等詞時分數 ×1.5。
        4. 新聞直接提到的公司，取「提到它的那幾句」的分數；只提到產業關鍵字的，相關族群取一半分數，標為「產業連動」。
        5. 總分 ≥ 1 為利多、≤ −1 為利空，絕對值 ≥ 4 為高影響。

        新聞發布前後的平均累積報酬

        影響程度 vs 命中率

        分數越強的預測應該越準；如果「高」沒有比「低」準，代表詞典權重需要調整。

        驗證規則

        基準價：新聞在 13:30 收盤前發布，取前一交易日收盤；收盤後發布，取當日收盤。
        實際方向：第 N 個交易日的報酬（或扣除大盤後的超額報酬）高於門檻為漲、低於負門檻為跌，其餘為持平。
        命中：預測利多且實際漲，或預測利空且實際跌。中性預測不計入命中率。
        交易日以證交所公布的開市日為準（颱風、國定假日休市不算）。

        新聞日期新聞個股預測基準價 → 第 N 日超額報酬結果

        運作流程

        1. 爬蟲讀各來源的 RSS 或文章列表頁，再讀文章頁取標題、時間與內文。每個網址先檢查 robots.txt，同一網站請求有間隔。
        2. 原文連結每則新聞以原文網址為唯一鍵，沒有網址就不收錄；網址會先去掉追蹤參數。
        3. 去重與儲存網址相同、或 3 天內標題相同的視為同一則，存進 SQLite。
        4. 詞典分析套用與原型相同的規則，再加上公司短名稱排除規則與產業連動的句子限制。
        5. 鎖定預測新聞存檔當下就把分數與詞典版本存檔，資料庫禁止事後修改。
        6. 收盤價收盤後抓證交所、櫃買中心的官方收盤價與加權指數。
        7. 自動驗證比對新聞後第 N 個交易日的股價，計算命中率；依結果調整詞典，再用「重算」比較新舊詞典。
        8. 網站這個頁面所有資料都來自後端 API（說明在 /docs）。

        新聞來自指定來源，完整內容請點標題閱讀原文。股價為證交所、櫃買中心公布的收盤價。分析結果僅為關鍵字規則推估，不構成投資建議。
