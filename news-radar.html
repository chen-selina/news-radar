      判斷規則

      1. 標題中的詞權重 ×1.5。
      2. 同一句中詞前 5 字內出現「未、不、無、沒有、並非」會把分數反轉，例如「未見砍單」算利多。
      3. 前方有「大幅、強勁、明顯」等詞時分數 ×1.5。
      4. 新聞直接提到的公司，取「提到它的那幾句」的分數；只提到產業關鍵字的，相關族群取一半分數，標為「產業連動」。
      5. 總分 ≥ 1 為利多、≤ −1 為利空，絕對值 ≥ 4 為高影響。

      新聞發布前後的平均累積報酬

      影響程度 vs 命中率

      分數越強的預測應該越準；如果「高」沒有比「低」準，代表詞典權重需要調整。

      驗證規則

      基準價：新聞在 13:30 收盤前發布，取前一交易日收盤；收盤後發布，取當日收盤。
      實際方向：第 N 個交易日的報酬（或扣除大盤後的超額報酬）高於門檻為漲、低於負門檻為跌，其餘為持平。
      命中：預測利多且實際漲，或預測利空且實際跌。中性預測不計入命中率。

      來源須為 Yahoo奇摩、Google新聞、商業周刊、天下雜誌、經濟日報其中之一；沒有原文網址的列會被略過。時間可省略（視為盤前）。內容含逗號時請用雙引號包住。

      正式上線時的運作流程

      1. 爬蟲只抓五個來源：Yahoo奇摩股市與 Google新聞 讀 RSS，經濟日報、商業周刊、天下雜誌讀文章列表頁，取標題、時間、原文網址與內文。
      2. 原文連結每則新聞以原文網址為唯一鍵，沒有網址就不收錄。Google新聞的轉址連結會先解析成原始媒體網址，兩者都存。
      3. 每日排程開盤前 08:00、收盤後 14:30 各跑一次（cron 或 GitHub Actions）。
      4. 去重與儲存以網址與標題雜湊去重，存進 SQLite 或 PostgreSQL。
      5. 詞典分析套用這個頁面的同一套規則，計算每則新聞與每檔個股的分數。
      6. 網站後端提供 API，這個頁面改成讀 API 資料，其餘介面不變。
      7. 鎖定預測新聞抓到當下就把分數與詞典版本存檔，事後不可修改，避免用事後資訊回頭改預測。
      8. 自動驗證每天收盤後抓證交所、櫃買中心收盤價，自動填入「預測驗證」的結果，再依命中率調整詞典權重。

      這個原型在瀏覽器內執行，無法直接連到新聞網站，所以「重新爬取」按鈕是模擬流程。「貼連結分析」則借用 Claude 桌面版的內建瀏覽器開啟網頁並擷取內文；正式版會改由後端爬蟲直接抓取，任何瀏覽器都能用。

      新聞為五個指定來源的真實報導，摘要以本站文字改寫，完整內容請點標題閱讀原文；部分付費或無法讀取的文章依標題摘要。「重新爬取」與驗證分頁的股價為模擬資料。分析結果僅為關鍵字規則推估，不構成投資建議。
