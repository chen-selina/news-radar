# 謝（Hsieh, 2015）財經情緒字典（外部資料）

`dictionary.tsv` 不是本專案編的，是從下列論文的附錄逐字轉錄：

- 李揚生 (2017)，《文字探勘與財經新聞：新聞是否會改變市場行為》，國立中山大學財務管理學系碩士論文（指導教授：馬黛）。
  附錄 1「Difference Between Lexicons」的「Positive (Hsieh, 2015)」「Negative (Hsieh, 2015)」兩張詞表（論文第 62～73 頁）。
- 字典原始出處：Hsieh (2015), *Predicting Company Revenue Trend Using Financial News*（以財經新聞預測公司營收）。
  它以 Lin (2013) 翻譯的 Loughran & McDonald (2011) 財務情緒字典為基礎修訂而成。

## 內容

- 正面 573 個詞、負面 593 個詞，共 1,166 個；只有方向（pos／neg），沒有強度，比照論文字典每個詞 ±1。
- 有 37 個單字詞（高、強、低、跌、空、差…），以及一些看起來和情緒無關的詞（召開、目標、注意、消息、可以）。
  這是原字典的內容，轉錄時沒有刪改。
- 和論文字典（`config/remi/`）重複 460 個詞，其中 7 個方向相反（和緩、減稅、獨占、空前、逆轉、開拓、開發）。
